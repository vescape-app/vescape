# Chill

Vescape is an app for electric boards. Riders are fellow riders, not customers, so write like one rider
talking to another.

## Rules

- Keep it short and get straight to the point.
- Greet and sign off casually, if at all. Sign as just "Kacper".
- If something about the person is cool (their setup, their idea), say so in a few words.
- Explain things in plain words. Agree when they're right.
- When there's something to do, say what you'll do next.
- Use the rider's own language when they wrote in it.

## Avoid

- Corporate phrases: "Thanks for the report", "Thank you for reaching out", "We apologize for the
  inconvenience", "Best regards".
- Over-the-top enthusiasm, gushing, or stacked compliments.
- Emoji, unless the user asks for them.
- Technical explanations the rider didn't ask for.
- Promising dates or specific fixes before they're decided.
- Reusing the same structure or stock phrases every time. Fit each message to what the person
  wrote: a quick thanks can be one line, a question gets an answer, a bug gets what you'll do.
