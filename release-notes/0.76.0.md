## New

- Vescape's core riding experience is now available on iPhone, including board connection, live telemetry, alerts, ride recording and history, privacy zones, Refloat tuning, and Tune Profiles.
- iPhone riders can follow connection, battery, and fault status from a Live Activity on the Lock Screen and Dynamic Island. Board faults can also raise a notification while the app is backgrounded when notification access is enabled.
- The Battery screen now includes detailed smart-BMS telemetry with cell voltages, balancing state, temperatures, health, humidity, current, and a shareable raw snapshot.

## Improved

- Board connections now keep retrying until the board returns instead of eventually giving up.
- Battery percentage, voltage, and current charts now share a synchronized scrubber, making load-related voltage sag easier to inspect.
- Vescape now uses the Raleway typeface throughout for clearer, more consistent text.
- Map and Group Ride updates use less processing power. Compass-follow mode has been temporarily disabled to prevent excessive battery use and device heating.

## Fixed

- Fixed Tune data sometimes remaining stale after reconnecting or returning to the app.
- Fixed duplicate or outdated ride-status notifications and Live Activities.
- Fixed map pins rendering incorrectly on iPhone.
- Native changes such as updated settings and saved battery readings now appear without restarting the app.
