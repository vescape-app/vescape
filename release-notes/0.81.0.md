## New

- Alert Presets provide Safe, Normal, Minimal, and Off protection levels for speed, duty, motor temperature, controller temperature, and battery. Individual metrics can still use custom alert rules.
- Vescape can now show update notices, important announcements, and required-update guidance directly in the app.
- Board Top Speed can be configured per board to scale speed gauges and preset alert thresholds appropriately.

## Improved

- Alerts are now stored separately for each board and can be configured during board setup or later in Board Settings.
- Legal Mode is now enabled per board and enforced by the native riding service, so its speed warnings continue without relying on the app interface. Enabling it requires a connected board with a trusted link.
